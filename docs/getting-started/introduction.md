# Introduction

Vibeswap is a LitVM LiteForge onchain arcade.

The app combines ranked games, leaderboards, GM streaks, swaps, and faucet mechanics in one simple product. The main product direction is competitive arcade gameplay with transparent onchain activity and future zkLTC reward seasons.

## What Vibeswap Includes

- Ranked games with onchain leaderboards.
- GM streaks tied to connected wallets.
- zkLTC and vbUSDC swap utilities.
- vbUSDC faucet for testing app flows.
- Future competitive seasons with zkLTC rewards.
