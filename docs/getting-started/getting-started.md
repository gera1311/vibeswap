# Getting Started

## 1. Open the App

Go to:

```text
https://vibeswap.net
```

## 2. Connect a Wallet

Use an EVM-compatible wallet and connect it to the app. If LitVM LiteForge is not added to your wallet, use the `Add to wallet` button in the app.

## 3. Get zkLTC

zkLTC is the native token used for gas and app fees on LitVM LiteForge.

You need zkLTC to:

- pay network gas;
- start ranked game runs;
- use GM, faucet, and swap mechanics.

## 4. Play Vibe Blocks

Open the `Vibe` tab, start a ranked run, and play the 2048-style game. Your score is submitted onchain when the run ends.

## 5. Track Your Rank

Vibeswap tracks two leaderboard types:

- Best Score: your highest single run.
- Total Score: your accumulated score across ranked runs.
