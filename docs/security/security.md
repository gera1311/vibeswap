# Security

## Current Assumptions

- Game moves are played in the browser.
- Final scores are submitted onchain after a ranked run.
- Current score validation is lightweight and suitable for early-stage testing.
- Larger public reward seasons should add stronger anti-cheat protection.

## Recommended Future Improvements

- Commit/reveal score submission.
- Server-side or verifier-assisted score validation.
- Season-specific contracts.
- Clear admin and treasury controls.
- Publicly documented reward distribution transactions.
- Contract verification in the LitVM explorer where supported.

## User Safety

Users should verify that they are connected to LitVM LiteForge and interacting with the official Vibeswap app:

```text
https://vibeswap.net
```
