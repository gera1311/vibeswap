# Vibeswap

Vibeswap is a LitVM LiteForge onchain arcade with ranked games, leaderboards, GM streaks, swaps, and faucet mechanics.

The project started as a DeFi utility app and is evolving into a competitive game hub. Swaps, faucet, and GM remain as utility modules, while games and seasonal leaderboards become the main product loop.

## Current Product

- Vibe Blocks: a 2048-style ranked game.
- Onchain leaderboard for best single score.
- Onchain leaderboard for total accumulated score.
- Paid game entry in zkLTC.
- GM streaks and badge progress.
- zkLTC / vbUSDC swaps.
- vbUSDC faucet for testing app flows.

## Core Direction

Vibeswap is focused on lightweight competitive games where players can enter ranked modes, compete during monthly seasons, and qualify for zkLTC rewards through transparent leaderboard results.

The long-term goal is to build a simple arcade layer for LitVM users: easy to try, competitive enough to return to, and connected to native zkLTC utility.
