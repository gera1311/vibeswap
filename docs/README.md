# Getting Started

Vibeswap is a LitVM LiteForge onchain arcade with ranked games, leaderboards, GM streaks, swaps, and faucet mechanics.

The project started as a DeFi utility app and is evolving into a competitive game hub. Swaps, faucet, and GM remain as utility modules, while games and seasonal leaderboards become the main product loop.

## Main Links

- App: https://vibeswap.net
- Docs: https://docs.vibeswap.net
- X: https://x.com/Vibeswapnet

## Current Focus

Vibeswap is focused on lightweight competitive games where players can enter ranked modes, compete during seasons, and qualify for zkLTC rewards through transparent leaderboard results.
