# Contests and Economic Model

Vibeswap is designed around competitive seasons and zkLTC reward pools.

The product direction is to run monthly seasons where players compete on leaderboards and top wallets can receive rewards. Reward pools should be funded before each season starts and gradually supported by app fees over time.

## Core Principles

- Seasons should have clear start and end dates.
- Rewards should be announced before the season starts.
- Leaderboards should be transparent and wallet-based.
- Fee distribution should be predictable and documented.
- Treasury usage should be visible to the community over time.
