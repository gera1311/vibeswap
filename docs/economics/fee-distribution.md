# Fee Distribution

Vibeswap fees are collected in zkLTC.

The long-term direction is to use fees to support the arcade economy instead of treating them only as revenue.

## Planned Distribution Areas

- Reward pools for future seasons.
- Treasury reserves.
- Swap liquidity support.
- Product and infrastructure costs.
- Ecosystem campaigns and partnerships.

## Reward Pool Direction

Each competitive season should start with a predefined zkLTC reward pool. During the season, a portion of game fees can gradually support future rewards.

This approach keeps season rewards predictable while allowing game activity to help sustain the next reward cycles.

## Current Status

The exact fee split is not final. It should be finalized before the first competitive season with zkLTC rewards.
