# Swaps

Swaps are utility mechanics inside Vibeswap.

The current swap module supports fixed-rate swaps between zkLTC and vbUSDC on LitVM LiteForge.

## Current Assets

- zkLTC: native LitVM LiteForge token used for gas and app fees.
- vbUSDC: test utility token used inside Vibeswap flows.

## Faucet

The faucet allows wallets to claim a small amount of vbUSDC after the cooldown period.

Current faucet behavior:

- 0.5 vbUSDC per claim.
- 24 hour cooldown per wallet.
- Small zkLTC faucet fee.

## Swap Utility

The swap module is not the main product direction anymore, but it remains useful for testing balances, token flows, and future in-app mechanics.
