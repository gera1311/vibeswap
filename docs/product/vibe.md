# Vibe

Vibe is the game section of Vibeswap.

The first game is Vibe Blocks, a 2048-style ranked game with onchain leaderboard tracking.

## Vibe Blocks

Players start a ranked run by paying the game entry fee in zkLTC. The game is played in the browser, and the final score is submitted onchain when the run ends.

## Leaderboards

Vibe Blocks currently has two leaderboard types:

- Best Score: the highest single run by wallet.
- Total Score: the accumulated score across ranked runs.

This structure allows both high-skill single runs and consistent seasonal activity to matter.

## Future Games

Future Vibe games may include risk/reward and online mechanics, including a Minesweeper-style game mode with zkLTC rewards for successful runs.
